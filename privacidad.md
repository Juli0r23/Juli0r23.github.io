## Datos que se recogen

El formulario de contacto recoge únicamente el nombre y la dirección de correo electrónico que el usuario introduce voluntariamente.

## Finalidad

Los datos se usan exclusivamente para responder al mensaje enviado. No se usan para publicidad, no se ceden a terceros y no se conservan más tiempo del necesario.

## Encargado del envío

El formulario utiliza [Formspree](https://formspree.io) como servicio de envío. Los datos pasan por sus servidores conforme a su [política de privacidad](https://formspree.io/legal/privacy-policy/).
